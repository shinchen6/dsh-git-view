# Git 视图

在对话页里查看、暂存、提交并推送当前仓库的 git 变更。

[English](README.md)

![整个文件](assets/whole.png)

## 功能

在对话页的 tab 环里，紧跟「轨迹」之后多一个 **Git**。它读的就是会话所在的那个
仓库 —— 不用配路径，不用另开一个界面。

- **分组展示变更** —— 冲突、已暂存、未暂存、未跟踪。目录行能整棵折叠，也能整棵
  暂存或丢弃。
- **三种看法** —— 整个文件（标出改动处）、只看变动（unified diff）、并排。选过的
  会被记住。
- **编辑保存** —— 在面板里改工作区文件并写回，保存时用读取时的版本号做校验。
- **分支、贮藏、拉取、同步** —— 以及刷新和丢弃。
- **提交与推送** —— 根据暂存内容生成提交信息；提交和推送分成两个按钮；推送前会先
  列出将要发布的每一条提交。

![只看变动](assets/changes.png)

未跟踪目录默认折叠，点开才向 git 询问那一个目录。所以一个有两万个未跟踪文件的工作区，
和只有二十个的，列出来的代价一样。

## 安装

需要 dsh 0.2.0-rc.2 或更新版本、Node 22.19+ 或 24+，以及一个工作目录是 git 仓库的会话。

```sh
dsh plugin --profile <profile> add shinchen6/dsh-git-view
```

然后重启该 profile，在对话里打开 **Git** tab。
